# Station 5: The Vault Remembers

> The vault will tell you its secret, but it will not repeat itself.

Let your badge wake the challenge. Watch every digit while the display is willing to speak.

When it goes dark, use the dial to give the secret back, one number at a time. Commit each choice carefully—the vault has more than one secret.

**Hint:** Memory opens the lock. The dial only proves it.
